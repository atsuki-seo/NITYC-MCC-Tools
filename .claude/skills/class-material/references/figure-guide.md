# 図版ガイド

`class-material` の Step 4（HTML生成）で参照する。図版はインラインSVGで記述する。

---

## 1. 原則

### 1.1 色値を直書きしない

配色は必ず共通クラス（`.svg-*`）で指定する。SVG内に `fill="#1f5f8b"` 等の色値を書くと、ダークモードで判読できなくなる。

例外: `marker` の `path` には `fill="var(--c-accent)"` のように CSS 変数を用いる（クラスが効かないため）。

### 1.2 アクセシビリティ

`role="img"` と `aria-label` を必ず付ける。`aria-label` には図が示す内容を文章で記述する。

```html
<svg viewBox="0 0 580 150" role="img" aria-label="添字 2 から 5 までの区間に 4 個の要素が含まれることを示す図">
```

### 1.3 サイズ指定

- `viewBox` のみを指定し、`width`/`height` 属性を付けない（CSS 側で `max-width: 100%` が効く）
- 横幅は 560〜580 を基準とする。これを超えるとスマートフォンで縮小され、文字が読めなくなる
- 文字サイズは `.svg-text`(15px) / `.svg-mono`(13px) / `.svg-small`(12px) に委ねる。SVG内で `font-size` を上書きしない

---

## 2. 共通クラス

| クラス | 用途 |
|--------|------|
| `.svg-cell` | 通常の枠（塗りあり）。データの入れ物を表す |
| `.svg-cell-plain` | 枠線のみ。文脈上の背景・対象外の要素 |
| `.svg-hl` | 強調枠。注目させたい要素・変化した箇所 |
| `.svg-text` | 主要なラベル（値・名前） |
| `.svg-mono` | 等幅。添字・アドレス・記号 |
| `.svg-small` | 補助説明・見出し |
| `.svg-line` | 補助線（灰色） |
| `.svg-arrow` | 矢印の線（アクセント色） |

`.svg-cell` と `.svg-hl` の対比で「通常」と「注目」を表現するのが基本である。

---

## 3. 頻出パターン

以下は特定テーマに限らず再利用できる図版の型である。テーマに応じて要素名を差し替える。

### 3.1 セル列 — 並んだ要素を示す

配列・メモリ領域・文字列・バッファなど、**同種の要素が並ぶ構造**に用いる。

構成:
- `rect` を等間隔・隙間なしで横に並べる（連続性を示す場合）
- 各セルの中央に `.svg-text` で値、下に `.svg-mono` で添字
- 注目させる要素だけ `.svg-hl` にする

```html
<rect x="40"  y="40" width="70" height="50" class="svg-cell-plain"/>
<rect x="110" y="40" width="70" height="50" class="svg-hl"/>
<text x="75"  y="71" class="svg-mono">[0]</text>
<text x="145" y="71" class="svg-mono">[1]</text>
```

隙間を空けると「連続していない」という誤解を生む。連続領域を示す場合は `x` を幅ちょうどずつ進める。

### 3.2 前後比較 — 状態の遷移を示す

操作の前後で構造がどう変わるかを示す。**挿入・削除・更新・並べ替え**など、動作を伴う概念に用いる。

構成:
- 上段に「操作前」、下段に「操作後」を配置
- 各段の上に `.svg-small` で見出し（「挿入前（要素数 4）」）
- 変化した要素を `.svg-hl` で示す
- 段の間に矢印を置き、操作内容を `.svg-small` で添える

縦に並べることで、同じ位置の要素を目で対応づけられる。左右に並べると対応関係が追いにくい。

### 3.3 上書きの表現

値が置き換わり、元の値が失われることを示す。

構成:
- 左に変更前の値（`.svg-cell`）、右に変更後の値（`.svg-hl`）
- 間に矢印と操作内容（`x ← 25`）
- 失われる値を破線枠（`.svg-cell-plain` + `stroke-dasharray="6 4"`）で示し、「失われる」と明記

```html
<rect x="420" y="45" width="110" height="60" class="svg-cell-plain" stroke-dasharray="6 4"/>
```

破線は「もう存在しない」「概念上の存在」を表す記法として一貫して用いる。

### 3.4 範囲の強調 — 区間を示す

添字の区間、探索範囲、対象部分列などを示す。

構成:
- 全体をセル列で描き、範囲内のみ `.svg-hl`
- 範囲の下に両端矢印と個数・長さの注記

「範囲内が何個か」を図から数えられるようにすることで、オフバイワンの誤解を視覚的に解消できる。

### 3.5 計算の注記 — 式と対象を結ぶ

計算結果がどの要素を指すかを示す。

構成:
- 図の上部に `.svg-mono` で式（`100 + 3 × 4 = 112`）
- そこから対象要素へ `.svg-arrow` で下向き矢印

式と結果の対応が一目で分かるため、アドレス計算・添字計算・インデックス変換に有効である。

## 4. 矢印の定義

矢印には `marker` が必要である。SVG ごとに一意な `id` を付ける（同一ページ内で衝突するため）。

```html
<path d="M 170 75 L 235 75" class="svg-arrow" marker-end="url(#ah3)"/>
...
<defs>
  <marker id="ah3" markerWidth="9" markerHeight="9" refX="8" refY="4.5" orient="auto">
    <path d="M 0 0 L 9 4.5 L 0 9 z" fill="var(--c-accent)"/>
  </marker>
</defs>
```

`id` の命名は `ah[通し番号]` とし、ページ内で重複させない。`<defs>` は各 SVG の末尾に置く。

---

## 5. 図版を入れる判断

**言葉で追いにくいものだけを図にする。** 箇条書きや表で十分な内容を図にしても、情報量は増えない。

| 図が有効 | 図が不要 |
|----------|---------|
| 構造の配置（何がどこにあるか） | 用語の定義 |
| 状態の遷移（操作前後の変化） | 分類の列挙（表が適切） |
| 位置・範囲の計算 | 性質の対比（表が適切） |
| 要素間の関係（参照・接続） | 手順の列挙（擬似コードが適切） |

分類・対比は `.table-scroll` の表、手順は `pre` の擬似コードを用いる。
