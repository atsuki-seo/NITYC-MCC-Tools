# 確認問題ガイド

`class-material` の Step 2（設計）と Step 4（生成）で参照する。

確認問題は授業中の理解確認と授業後の自習の双方で用いる。解答は問題のすぐ下にアコーディオンで配置し、学生が自力で考えてから確認できるようにする。

---

## 1. 配置と個数

- **各節に1問以上**を配置する。節の末尾（その節の内容を読み終えた直後）に置く
- 節の内容だけで答えられる問題とする。他の節の知識を要する問題は、その知識を扱う節に置く
- 1節に複数問置く場合は `.quiz + .quiz` で連続させる

問題番号は `確認問題 [節番号]-[連番]` とする（`確認問題 3-1`）。節番号は `h2` の `.num` と一致させる。

## 2. 問題形式

| 形式 | 用途 |
|------|------|
| 4択 | 概念の弁別、性質の理解。既定の形式 |
| 手順追跡 | 擬似コードを提示し、実行後の状態を問う |
| 計算 | 添字計算・要素数・計算量など、数値で答えが定まるもの |

記述式は自動採点ができず、解答の正誤を学生が自己判断しにくいため、原則用いない。

## 3. 誤答選択肢の設計

**誤答選択肢には、典型的な誤解を1つずつ割り当てる。** 明らかに誤りと分かる選択肢を並べてはならない。

| 選択肢 | 割り当てる誤解 |
|--------|---------------|
| 正解 | — |
| 誤答1 | 概念の混同（似た概念と取り違える） |
| 誤答2 | 範囲の誤り（オフバイワン、境界条件の誤解） |
| 誤答3 | 因果の誤り（関係のない要因を原因と考える） |

すべての誤解を毎回使う必要はないが、**各誤答が「なぜそう考えてしまうか」を説明できる**ことを要件とする。説明できない選択肢は、学生にとって選ぶ理由がなく、実質3択以下になる。

### 例

```
ある変数に「整数型」を指定した。この指定によって定まる事柄として、
最も適切なものはどれか。

(A) その変数が配置されるメモリの番地      ← 型と記憶域の混同
(B) その変数が保持しうる値の範囲と、適用可能な演算  ← 正解
(C) その変数を参照した際の処理速度        ← 型と性能の因果の誤り
(D) その変数に付与すべき名前の形式        ← 型と命名規則の混同
```

## 4. 解説の書き方

**正解の根拠だけでなく、全ての誤答がなぜ誤りかに言及する。** 学生は誤答を選んだ場合にこそ解説を読むため、自分が選んだ選択肢への言及がなければ解説の意味がない。

構成:

1. `.verdict` で正解を明示（`正解: (B)`）
2. 正解の根拠を述べる
3. 各誤答について、なぜ誤りかを述べる

```html
<details class="answer">
  <summary><span>解答</span></summary>
  <div class="answer-body">
    <p class="verdict">正解: (B)</p>
    <p>
      データ型が定めるのは、値域と許容される操作の二点である。
    </p>
    <p>
      (A) の番地は処理系が決定する事項であり、型の役割ではない。
      (C) の処理速度はアルゴリズムと処理系の最適化に依存する。
      (D) の命名は言語の規則および開発者の判断に属し、型とは独立である。
    </p>
  </div>
</details>
```

## 5. マークアップ

選択肢は `ol.choices` を用いる。**`(A)` 等の記号を手で書かない。** CSS カウンタが自動採番する。

```html
<div class="quiz">
  <span class="quiz-label">確認問題 3-1</span>
  <p class="q-body">
    変数 a と b がある。次の操作を上から順に実行したとき、
    最終的に a と b が保持する値の組合せとして正しいものはどれか。
  </p>
  <pre><code>1. a ← 3
2. b ← 8
3. a ← b
4. b ← 5</code></pre>
  <ol class="choices">
    <li>a は 3、b は 5</li>
    <li>a は 8、b は 5</li>
    <li>a は 5、b は 5</li>
    <li>a は 8、b は 8</li>
  </ol>
  <details class="answer">
    <summary><span>解答</span></summary>
    <div class="answer-body">
      <p class="verdict">正解: (B)</p>
      <p>...</p>
    </div>
  </details>
</div>
```

注意点:

- `summary` の中身は `<span>解答</span>` とする。表示ラベルは CSS の `::before` が制御するため、この `span` は非表示になる
- `details` に `open` を付けない（既定は閉じた状態）
- JavaScript を用いない。`details`/`summary` のネイティブ挙動のみで完結させる

## 6. 小テスト論点の再構成

直近の小テストの論点を確認問題に織り込む場合（`content-design-guide.md` § 3）、設問文をそのまま転載しない。以下のいずれかで再構成する:

- 数値・変数名・文脈を変える
- 問う角度を変える（「結果はどれか」→「この結果になる操作はどれか」）
- 形式を変える（選択式 → 手順追跡）

「小テストで出題した」等の言及はしない。
